

# Namify

**Namify** is a sample project demonstrated during the **A-SYS Webinar** on **July 25, 2025, 2:00 PM**, focused on **AI and System Making**.

## Overview

Namify is a lightweight Web4-based system designed to **organize names alphabetically**, **count occurrences**, and **generate a summary**, 
which can be **exported as a text file**. It provides a practical solution for educators or professionals handling large sets of names that require structured formatting and reporting.

## Background

This tool was inspired by the organizational needs of **Ms. Atali**, 
who manages a large number of students. With increasing name records, the need for a fast and accurate sorting method became clear.
One student (**Nai**)  took the initiative to design a system that solves this problem efficiently which resulting in the creation of Namify.

## Features

* Alphabetical sorting of names
* Counting and tallying of name occurrences
* Display of total names
* Export to plain `.txt` format for sharing or archival
